# dotfiles, session context

## What this branch is

**Branch:** `machine/macbook-i9`, branched from `machine/workforce` on 2026-10-03. This machine is a used Intel i9 MacBook on macOS 26 (Darwin 25.6). Terminal and CLI configs only: zsh, Neovim, tmux, k9s, btop, bat, Ghostty and Zed. Light theme throughout, Gruvbox Light, not generated by Noctalia (there is no Noctalia here).

Homebrew has dropped Intel support, so packages come from MacPorts, the official mise binary (`~/.local/bin/mise`) and a few manual installs. The full list and the install commands are in `MACOS.md` at the repo root, which is the source of truth for this machine.

Do not merge `main` or `machine/workforce` into this branch. The branches have deliberately diverged (different OS, compositor, shell and theming). Cross-pollinate by cherry-picking specific commits only. The other machine branches are `machine/workforce` (ThinkPad, Arch, niri) and `machine/ri-t-0931`.

Git identity is set at `--local`: `Naeem Arshad <naimarshad@gmail.com>` (personal repo). Commits are one-line Conventional Commits with the package as scope, one commit per package, and no assistant attribution.

## Machine facts worth knowing

- **Packages:** MacPorts under `/opt/local` for native CLI tools. mise (official binary, not MacPorts) for `kubectl helm go node rust python@3.13`. `.zshrc` puts `~/.local/bin` and `/opt/local/bin` on PATH.
- **Python:** the system `python3` is 3.9 and is too old for `jaberos/memory_extractor.py`, which uses `X | None` annotations. The mise `python@3.13` is the one that must be first on PATH.
- **Stow packages used here:** `zsh nvim tmux k9s btop bat zed ghostty`. `niri hypr fish starship gtk fontconfig arch-update noctalia` are not stowed, and `zed-noctalia-icons/` is not installed. `~/.kube` is linked as a directory into `zsh/.kube`, so never commit kubeconfigs.
- **Shell:** oh-my-zsh with Powerlevel10k, plus mise and mcfly. The oh-my-zsh theme and custom plugins are git clones in `~/.oh-my-zsh/custom` and are not in this repo. `omp` is oh-my-pi, installed with its official curl installer.
- **Theme files:** Zed `Gruvbox Light`, Ghostty `Gruvbox Light`, bat `gruvbox-light`, btop MacPorts' `gruvbox_light.theme`, k9s `skins/gruvbox-light.yaml`, tmux `themes/gruvbox-light.conf`, Neovim `lua/gruvbox_light.lua`. The Noctalia-generated files stay in the repo for the Linux machines and are not loaded here.
- **tmux:** no theme plugin. The status line is plain tmux formats. `scripts/battery.sh` and `scripts/net.sh` have a Darwin branch (`pmset`, `route`, `networksetup`), so keep both branches when editing them.
- **k9s:** needs `K9S_CONFIG_DIR=$HOME/.config/k9s`, which `.zshrc` exports, because macOS defaults to `~/Library/Application Support/k9s`.
- **Fonts:** Monaspace (variable for Ghostty, static for Zed) and `Symbols Nerd Font Mono` live in `~/Library/Fonts`, copied from the official releases.
- **Claude Code memory:** the Obsidian vault is `~/Obsidian`, synced by syncthing. The tooling is `~/jaberos` (hooks and the `jev` and `memory-recall` skills), installed with `install.sh`. This machine's `~/.claude/memory-extractor.json` has `machine: "macbook-i9"` and no routes. `~/Obsidian/MEMORY.md` is frozen to assistants by a `PreToolUse` hook in `~/.claude/settings.json`.

## Neovim IDE setup

The LazyVim-based setup carried over from `machine/workforce`. Languages: Go, Rust, plus DevOps (Shell, Docker, YAML, Helm, JSON, TOML, Markdown, Git). AI: `coder/claudecode.nvim` and Supermaven ghost text. Colours come from `lua/gruvbox_light.lua` through base16-nvim, wired up in `lua/plugins/base16.lua` and `lua/plugins/colorscheme.lua`. Extras live in `nvim/.config/nvim/lazyvim.json`. `:Lazy sync` on a fresh install can fail with `Could not resolve host: github.com` when the home router's DNS resolver is flooded; re-running it converges.
